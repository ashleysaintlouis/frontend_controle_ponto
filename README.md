# Frontend - Controle de Ponto

## Como rodar

```bash
cd frontend-controle-ponto-sistema
npm install
npm run dev
```

A aplicação fica em:

- http://localhost:5173

## Variáveis de ambiente

Crie um arquivo `.env` com:

```env
VITE_API_URL=http://localhost:3333
```

## Build

```bash
npm run build
```

Para instruções completas do backend, Prisma e Swagger, consulte o README raiz do projeto em [README.md](../README.md).
